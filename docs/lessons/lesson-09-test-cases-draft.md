# سبق ۹ — آزمائشی صورتوں کا مسودہ

## مقصد اور حدود

یہ آزمائشی صورتیں صرف سبق ۹ کی عبارت کو جانچنے کے لیے بنائی گئی ہیں۔ یہ **ٹیسٹ کی وضاحتیں ہیں، چلائے گئے خودکار ٹیسٹ نہیں**؛ حسابی انجن میں کوئی قاعدہ نافذ نہیں کیا گیا۔ ہر صورت میں صرف متعلقہ اختِ علّی کا حکم درج ہے، مکمل ترکہ تقسیم نہیں۔

**اس پیراگراف کا بنیادی ماخذ:** `droos siraji simple.pdf`، PDF صفحات ۶–۷ (مطبوعہ صفحات ۳–۴)۔ البُشریٰ معاون ماخذ ہے۔

## جانچ کے اصول

1. یہ ٹیسٹ صرف سبق ۹ کے بیان کردہ احکام جانچتے ہیں؛ حصص کے مجموعے، عَول، رَد، ذوی الارحام، یا دوسرے اسباق کے احکام ان میں شامل نہیں۔
2. ہر ٹیسٹ میں مذکور نہ ہونے والے رشتے فرض نہیں کیے جائیں گے۔ جب اسے مکمل inheritance fixture میں بدلا جائے تو باقی وارثوں کی فہرست واضح طور پر متعین کرنا ہوگی۔
3. L09-T01 میں «اخِ عینی» کو «اختِ عینی» نہ سمجھا جائے؛ اسکین میں دونوں اصطلاحات الگ الگ صورتوں میں آتی ہیں۔
4. ان ٹیسٹوں کو کوڈ میں نافذ کرنے سے پہلے صارف کی منظوری اور تمام متعلقہ شرائط کا ماخذی آڈٹ ضروری ہے۔
