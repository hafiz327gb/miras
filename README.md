# مشروع میراثِ سراجی

یہ ریپوزٹری کتاب **دروسِ سراجی** کی بنیاد پر میراث کے مسائل کے لیے ایک ماخذ-مقید (source-locked) کیلکولیٹر تیار کرنے کا منصوبہ ہے۔

## بنیادی اصول

- میراث کے قواعد کے لیے بنیادی ماخذ ریپوزٹری میں موجود PDF نسخے ہوں گے۔
- `index.html` صرف موجودہ UI اور وضاحتی انداز کا نمونہ ہے؛ اس کے حسابی فارمولوں کو کتابی قواعد کا ماخذ نہیں سمجھا جائے گا۔
- کتاب کے متن سے اختلاف رکھنے والی کسی تبدیلی کو صارف کی واضح منظوری کے بغیر نافذ نہیں کیا جائے گا۔
- ہر نافذ کردہ قاعدے کے ساتھ سبق، مطبوعہ صفحہ (اگر دستیاب ہو)، PDF صفحہ، اصل عبارت، اور متعلقہ ٹیسٹ درج کیا جائے گا۔
- دونوں PDF نسخوں میں اختلاف یا غیر واضح عبارت کی صورت میں قاعدہ خودکار طور پر نافذ نہیں ہوگا؛ پہلے اس کی نشاندہی اور انسانی تصدیق ضروری ہوگی۔
- **غیر واضح متن کا لازمی طریقۂ کار:** اندازہ نہ لگائیں؛ سبق، نسخہ، صفحہ اور غیر واضح حصہ بتا کر اسی وقت صارف سے تصحیح پوچھی جائے۔ تصدیق تک اسے `UNCLEAR` رکھا جائے۔
- **صفحہ نمبروں کا لازمی اصول:** دونوں PDF نسخوں کے صفحات الگ الگ درج کیے جائیں۔ ایک نسخے کے صفحہ نمبر سے دوسرے نسخے کا صفحہ اخذ نہ کیا جائے؛ ہر نسخے میں سبق کا مقام الگ تلاش اور تصدیق کیا جائے۔

## ریپوزٹری کے موجودہ ماخذ

- `Durus Siraji - Al Bushra.pdf`
- `droos siraji simple.pdf`
- `index.html` — صرف UI/وضاحت کے نمونے کے طور پر

## مجوزہ مراحل

1. **مرحلہ 1 — بنیاد اور فنِ تعمیر:** ماخذ کے اصول، فولڈر کی ساخت، اور ضابطۂ حوالہ متعین کرنا۔ بنیادی دستاویزات بنائی گئی ہیں۔
2. **مرحلہ 2 — کتابی متن کی فہرست:** دونوں PDF نسخوں کے اسباق، صفحات، اصطلاحات اور قواعد کی تصدیق شدہ فہرست بنانا۔ ابتدائی نسخہ نقشہ تیار ہے؛ مکمل جانچ جاری ہے۔
3. **مرحلہ 3 — قواعد کی رسمی صورت:** ہر قاعدے کو حوالہ اور شرائط کے ساتھ درج کرنا؛ ابھی حسابی انجن میں نافذ نہیں کرنا۔
4. **مرحلہ 4 — حسابی انجن:** صرف تصدیق شدہ قواعد نافذ کرنا۔
5. **مرحلہ 5 — آزمائش:** کتابی مثالوں، سرحدی صورتوں، اور غلط/نامکمل ان پٹ کے ٹیسٹ بنانا۔
6. **مرحلہ 6 — UI انضمام:** موجودہ نمونے سے صرف منظور شدہ UI انداز اخذ کرکے انجن سے جوڑنا۔
7. **مرحلہ 7 — آڈٹ اور اجرا:** نتائج، حوالہ جات، حدود اور باقی غیر مصدقہ امور کی جانچ۔
